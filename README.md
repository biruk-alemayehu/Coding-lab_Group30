# Coding-lab_Group30: Kenyatta National Hospital (KNH) Digital Infrastructure

## 📌 Project Overview
This repository contains the automated infrastructure and log management tools built for Kenyatta National Hospital (KNH). The system secures medical data streams generated by 12 critical sensors (Heart Rate, Temperature, and Water Usage), ensures strict file permission standards, generates analytical alerts for emergencies, and manages log archiving without data loss.
